01 / DESCRIPCIÓN

Del sensor a una
decisión informada.

El Internet de las Cosas permite conectar dispositivos físicos para recopilar y transmitir información. En este proyecto, un sensor ambiental obtiene datos de temperatura y humedad, que pueden enviarse mediante un microcontrolador y MQTT a una interfaz de monitoreo.

💡
Objetivo del proyecto

Representar el monitoreo ambiental, detectar valores elevados y registrar eventos importantes.

03 / GUÍA DE IMPLEMENTACIÓN

Ocho pasos para ponerlo
en marcha.

Etapas propuestas para construir y comprobar un sistema de monitoreo ambiental IoT.

01
🔌

Conectar el sensor

Conectar el sensor al microcontrolador siguiendo el esquema del fabricante. Comprobar alimentación, voltaje, GND y pines de datos.

Hardware
02
💻

Preparar el programa

Instalar las bibliotecas necesarias y cargar un programa que lea temperatura y humedad periódicamente. Revisar las lecturas en el monitor serial.

Programación
03
📶

Configurar Wi-Fi y MQTT

Configurar la red y el cliente MQTT. Guardar las credenciales fuera del código que se comparte públicamente.

Conectividad
04
📨

Publicar los datos

Publicar temperatura, humedad y marca temporal en un tema MQTT como aula/ambiente, utilizando un mensaje JSON.

Mensajería
05
📊

Configurar el panel

Configurar un cliente suscriptor para recibir los mensajes y visualizar las mediciones en una interfaz gráfica.

Visualización
06
🔔

Definir las alertas

Establecer un umbral de demostración, activar una alerta visual cuando se supere y registrar la hora del evento.

Alertas
07
🌐

Probar la desconexión

Desconectar temporalmente la red, observar la interrupción de mensajes y luego restaurar la conexión para comprobar su recuperación.

Pruebas
08
📷

Documentar evidencias

Tomar capturas propias de la lectura del sensor, la recepción del mensaje MQTT y el panel funcionando. Añadir fecha y descripción.

Documentación
